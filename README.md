## ⚡ Live Features & Capabilities

- **🌌 60 FPS Cyber Particle Network Canvas**: Dynamic cybersecurity / neural network particle mesh with cursor attraction and repulsion physics.
- **🛡️ Interactive Cyber Credential Viewer Modal**: Complete document inspection viewer allowing visitors to click and preview official certificates with one-click download, new-tab fullscreen view, and live portal verification links.
- **💻 Interactive Command Terminal (`Ctrl + K` or `/`)**: Embedded cyber terminal CLI supporting interactive commands: `projects`, `certs`, `skills`, `about`, `contact`, `clear`, and `help`.
- **📐 3D Perspective Card Tilt**: Dynamic mouse-driven 3D tilt with real-time specular spotlight reflection on cards.
- **🔐 Decryption Text Scramble**: Matrix-inspired text decryption animations on section headers.
- **📈 Telemetry Numerical Count-Up**: Smooth animated count-up metrics for academic and model evaluation data.
- **📱 100% Responsive**: Engineered with semantic HTML5, modern CSS3 (Custom Properties, Flexbox, Grid), and vanilla ES6+ JavaScript.

## 🌐 Deploying to GitHub Pages

1. Create a new repository on GitHub: [github.com/new](https://github.com/new)
   - Name: `portfolio` (or `subhojitshaw58-png.github.io`)
   - Visibility: **Public**
2. Upload the project files (`index.html`, `css/`, `js/`, `assets/`, `README.md`).
3. In your repository on GitHub:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment > Branch**, choose **`main`** and **`/(root)`**
   - Click **Save**
4. Within 1-2 minutes, your website will be live worldwide at:
   `https://subhojitshaw58-png.github.io/portfolio/`
